BrainQuest Kids is an interactive educational learning app designed to make studying fun, engaging, and rewarding for children.

The app combines daily learning tasks with fun brain games to help children practice important skills while staying motivated. Kids can complete tasks, earn XP and stars, build learning streaks, and challenge themselves with interactive games.

Key Features
📚 Daily learning tasks
🎮 Fun educational brain games
⭐ XP and star rewards
🔥 Learning streak tracking
🧩 Memory, pattern, sequence, and reaction challenges
📊 Progress tracking and performance insights
👨‍👩‍👧 Parent progress view
💾 Saves learning and game progress

BrainQuest Kids is designed to turn everyday learning into a fun experience where children can learn, play, and track their progress along the way.

Learn. Play. Earn. Grow. 🚀
